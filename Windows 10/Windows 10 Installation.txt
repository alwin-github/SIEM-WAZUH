Installation of Windows 10 on VirtualBox

Step 1: Prerequisites
	Install Oracle VM VirtualBox
	Download Windows 10 ISO file from official Microsoft website
	Minimum system requirements:
	4 GB RAM (recommended 8 GB)
	50 GB free storage

Step 2: Create Virtual Machine
	Open VirtualBox
	Click New
	Enter Name: Windows 10
	Type: Microsoft Windows
	Version: Windows 10 (64-bit)
	Click Next

Step 3: Allocate Memory (RAM)
	Minimum: 2 GB (2048 MB)
	Recommended: 4 GB or more
	Click Next

Step 4: Create Virtual Hard Disk
	Select Create a virtual hard disk now
	Choose VDI (VirtualBox Disk Image)
	Select Dynamically Allocated
	Set size: 50 GB or more
	Click Create

Step 5: Attach Windows 10 ISO
	Select the VM → Click Settings
	Go to Storage
	Under Controller IDE → Empty
	Click disk icon → Choose a disk file
	Select Windows 10 ISO
	Click OK

Step 6: Start Installation
	Select VM → Click Start
	Windows setup screen will appear

Step 7: Windows Setup Configuration
	Select:
	Language
	Time & Currency
	Keyboard layout
	Click Next → Install Now

Step 8: License Key
	Enter product key OR
	Click I don’t have a product key (for trial)

Step 9: Select Version
	Choose Windows 10 Pro (recommended)
	Click Next

Step 10: Installation Type
	Select Custom: Install Windows only (Advanced)

Step 11: Disk Partition
	Select the virtual disk
	Click Next
	Installation will begin

Step 12: Installation Process
	Files will copy and system will restart automatically
	Wait for setup to complete

Step 13: User Setup
	Enter:
	Username
	Password
	Configure:
	Privacy settings
	Network options

Step 14: Windows Desktop
	Windows 10 will load successfully
	You will see the desktop screen

Step 15: Install Guest Additions (Important)
	Go to Devices → Insert Guest Additions CD Image
	Run setup inside Windows
	Restart VM

👉 This improves:

	Display resolution
	Performance
	Mouse integration
